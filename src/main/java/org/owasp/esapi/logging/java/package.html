This package contains the ESAPI {@code Logger} implementation that writes to the {@code java.util.logging} API. {@code JavaLogFactory} creates the loggers, and the bridge and level handler classes map ESAPI log levels to Java logging levels. Select this implementation with the {@code ESAPI.Logger} property. Output is configured the usual way for {@code java.util.logging}, for example with the {@code java.util.logging.config.file} system property.
