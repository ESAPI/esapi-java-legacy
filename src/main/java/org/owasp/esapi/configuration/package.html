This package contains the classes that load ESAPI configuration properties from more than one file. {@code EsapiPropertyManager} looks a property up in a higher priority file kept by the operations team and then in a lower priority file kept by the development team. The paths of these files come from the {@code org.owasp.esapi.opsteam} and {@code org.owasp.esapi.devteam} system properties. Values in the lower priority file never override the higher priority file. Both standard Java properties files and XML files are supported.
